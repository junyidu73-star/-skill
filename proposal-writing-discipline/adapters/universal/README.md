# 通用接入（DeepSeek、GPT、Gemini、Kimi、通义等）

网页模型没有文件系统，规则只能通过提示词进入上下文。这里提供两个版本。

| 文件 | 适用 | 字数 |
| --- | --- | --- |
| `system-prompt.md` | 完整版，与 `SKILL.md` 同源，建议优先使用 | 约 3000 字 |
| `system-prompt-compact.md` | 精简版，保留强制项，删掉举例，适合 8k 到 16k 上下文 | 约 900 字 |

## 粘贴方法

- 有自定义指令或系统提示词的平台（DeepSeek 的自定义指令、ChatGPT 的 Custom Instructions、Claude 的 Project Instructions），把全文放进“系统提示词”栏。
- 没有系统提示词栏的平台，把全文作为对话第一条消息发出，再用一句话确认“以上规则已生效，后续按它执行”。
- 长文档分段提交时，每次新开会话都要重新粘贴，规则不会跨会话保留。

## 精简版的位置

`system-prompt-compact.md` 是派生文件，不是另一套规则。内容与完整版一致，只压缩了说明性文字。两者冲突时以 `SKILL.md` 为准。

## 实际效果差异

网页模型的工具能力差异较大。能联网检索并读全文的模型可以走完第六部分的引用流程；只能读摘要的模型应当主动标“仅摘要”或【待核实】，不要改成看似确定的表述。终审报告里的“无法验证项”一栏就是给这种情况留的。
